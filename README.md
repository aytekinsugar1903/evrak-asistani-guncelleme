# Evrak Asistanı — Güncellemeler

Okullar için Evrak Asistanı sürümleri. Son sürümü **Releases** bölümünden indirin.

## Kurulum / güncelleme
1. Releases'tan son `evrak-asistani-vX.Y.Z.zip` dosyasını indirin ve bir klasöre çıkarın.
2. Chrome → `chrome://extensions` → sağ üstte **Geliştirici modu** açık.
3. Eski sürüm varsa **Kaldır**; sonra **Paketlenmemiş öğe yükle** → çıkardığınız klasörü seçin.
4. Ayarlarınız ve kayıtlarınız kaldırma sırasında silinebilir: önce eklentideki 📤 yedek düğmesiyle yedek alın.

`surum.json` eklentinin güncelleme ve acil durdurma kontrolü içindir; elle değiştirmeyin.
